# Учебные задачи по Dart - Модуль 1, Урок 2

Добро пожаловать в коллекцию учебных задач для начинающих разработчиков на Dart!

## 📚 О проекте

Этот проект содержит **60 практических задач** по 6 основным темам Dart для совсем начинающих разработчиков. Каждая задача разработана с учетом того, что вы только начинаете изучать программирование.

### Темы курса:

1. **Variables (Переменные)** - var, const, final, late, область видимости
2. **Data Types (Типы данных)** - String, int, double, bool, num, dynamic, Object
3. **List (Списки)** - создание, методы, операции со списками
4. **Map (Словари)** - ключ-значение, вложенные структуры
5. **Set (Множества)** - уникальность, операции над множествами
6. **Null Safety** - nullable типы, операторы ?., ??, !

### Уровни сложности:

| Уровень | Описание | Количество на тему |
|---------|----------|---------------------|
| 🟢 **Easy** | Базовые концепции, простые операции | 4 задачи |
| 🟡 **Medium** | Комбинирование концепций, практика | 4 задачи |
| 🔴 **Hard** | Продвинутые техники, комплексные задачи | 2 задачи |

## 🚀 Как работать с задачами

### Шаг 1: Откройте задачу

```bash
# Перейдите в папку с задачами
cd tasks/variables

# Откройте первую задачу в редакторе
code task_01_easy.dart
# или
nano task_01_easy.dart
# или откройте в вашей IDE
```

### Шаг 2: Прочитайте задание

Каждая задача содержит:

```dart
// ОПИСАНИЕ:
// Объяснение концепции, которую вы будете изучать

// ЧТО НУЖНО СДЕЛАТЬ:
// Пошаговые инструкции (обычно 5-10 шагов)

// ЧТО МЫ ДОЛЖНЫ ПОЛУЧИТЬ:
// Ожидаемый результат - как должна выглядеть программа

void main() {
  // Напишите ваш код здесь

}
```

### Шаг 3: Напишите код

Напишите ваше решение внутри функции `main()`:

```dart
void main() {
  // Ваш код
  var name = 'Иван';
  var age = 20;
  print('Меня зовут $name, мне $age лет');
}
```

### Шаг 4: Запустите программу

```bash
# Запуск из папки с задачей
dart task_01_easy.dart

# Или из корня проекта
dart tasks/variables/task_01_easy.dart
```

### Шаг 5: Проверьте результат

Сравните вывод вашей программы с ожидаемым результатом из секции "ЧТО МЫ ДОЛЖНЫ ПОЛУЧИТЬ".

## 💡 Если застряли

### 1. Посмотрите подсказки

Для каждой задачи есть файл с подсказками в папке `hints/`:

```bash
# Откройте файл с подсказками
cat tasks/variables/hints/task_01_hints.md

# Или откройте в редакторе
code tasks/variables/hints/task_01_hints.md
```

**Подсказки содержат:**
- Пошаговое решение (без готового кода!)
- Синтаксис и примеры
- Частые ошибки
- Дополнительные примеры

### 2. Посмотрите готовое решение

Если подсказки не помогли, посмотрите готовое решение:

```bash
# Запустите готовое решение
dart solutions/variables/task_01_solution.dart

# Откройте код решения
code solutions/variables/task_01_solution.dart
```

**Решения содержат:**
- Полный рабочий код
- Подробные комментарии на русском
- Объяснение ПОЧЕМУ именно так
- Альтернативные подходы

### 3. Стратегия "подсказки → попытка → решение"

```
1. Попробуйте решить сами (5-10 минут)
   ↓
2. Если не получается → откройте hints
   ↓
3. Прочитайте первую подсказку → попробуйте снова
   ↓
4. Если все еще не получается → следующая подсказка
   ↓
5. Если совсем застряли → посмотрите solution
```

## 📝 Как проверять задания

### Самостоятельная проверка

1. **Запустите вашу программу:**
   ```bash
   dart tasks/variables/task_01_easy.dart
   ```

2. **Сравните вывод** с секцией "ЧТО МЫ ДОЛЖНЫ ПОЛУЧИТЬ" в задаче

3. **Если вывод совпадает** - задача решена! ✅

4. **Если не совпадает** - проверьте:
   - Правильно ли вы понимаете задание?
   - Все ли шаги выполнены?
   - Нет ли опечаток в коде?

### Проверка через готовое решение

1. **Запустите готовое решение:**
   ```bash
   dart solutions/variables/task_01_solution.dart
   ```

2. **Сравните вывод** вашей программы и готового решения

3. **Если выводы совпадают** - отлично! ✅

4. **Откройте код решения** и сравните подходы:
   ```bash
   code solutions/variables/task_01_solution.dart
   ```

### Проверка преподавателем

Если вы работаете с преподавателем:

1. **Сохраните ваше решение** в отдельном файле:
   ```bash
   cp tasks/variables/task_01_easy.dart my_solutions/task_01_my_solution.dart
   ```

2. **Покажите преподавателю:**
   - Ваш код
   - Вывод программы
   - Объяснение как вы решили задачу

3. **Получите обратную связь** по:
   - Правильности решения
   - Качеству кода
   - Возможным улучшениям

## 🎓 Советы по обучению

### 1. Не спешите

⏱ **Рекомендуемый темп:**
- Легкая задача: 10-20 минут
- Средняя задача: 20-40 минут
- Сложная задача: 40-60 минут

Лучше потратить больше времени и разобраться, чем быстро решить не понимая.

### 2. Пишите код сами

❌ **Не копируйте** решения из интернета или готовых ответов
✅ **Печатайте** каждую строку кода самостоятельно
✅ **Экспериментируйте** - меняйте код и смотрите что произойдет

### 3. Используйте подсказки правильно

📖 **Правильная последовательность:**
1. Попытка решить самому (минимум 5-10 минут)
2. Первая подсказка → новая попытка
3. Вторая подсказка → новая попытка
4. Решение (если совсем не получается)

🚫 **Не открывайте сразу все подсказки!**

### 4. Делайте перерывы

После каждых 4-5 задач делайте перерыв:
- ☕ 10-15 минут отдыха
- 🚶 Прогулка
- 🧠 Осмысление изученного

### 5. Повторяйте материал

📚 **Стратегия повторения:**
- День 1: Решите задачи 1-4 (Easy)
- День 2: Повторите задачи 1-4, решите 5-8 (Medium)
- День 3: Повторите 5-8, решите 9-10 (Hard)
- День 7: Повторите все задачи темы

### 6. Объясняйте код

После решения задачи:
1. Объясните код самому себе вслух
2. Напишите комментарии к каждой строке
3. Расскажите кому-нибудь как вы решили задачу

## 🆘 Частые проблемы

### Программа не запускается

```bash
Error: Could not find a file named "pubspec.yaml"
```

**Решение:** Dart файлы можно запускать напрямую:
```bash
dart task_01_easy.dart
```

### Непонятная ошибка компиляции

```bash
Error: Expected ';' after this.
```

**Решение:**
1. Проверьте точку с запятой в конце строки
2. Проверьте закрывающие скобки
3. Проверьте кавычки в строках

### Вывод не совпадает с ожидаемым

**Что проверить:**
1. Правильность имен переменных
2. Правильность вычислений
3. Формат вывода (пробелы, переносы строк)
4. Порядок вывода данных
