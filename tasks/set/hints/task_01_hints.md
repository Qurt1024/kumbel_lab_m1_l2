# Подсказки к Задаче 1: Создание первого множества Set

## Подсказка 1: Что такое Set?
Set (множество) - это коллекция уникальных элементов. Главная особенность:
- Автоматически удаляет дубликаты
- Элементы не имеют индексов
- Порядок элементов не гарантирован

## Подсказка 2: Создание Set
Есть несколько способов создать множество:
```dart
// Способ 1: Литерал множества
var fruits = {'яблоко', 'банан', 'апельсин'};

// Способ 2: С указанием типа
Set<String> fruits = {'яблоко', 'банан', 'апельсин'};

// Способ 3: Пустое множество
var emptySet = <String>{};
Set<int> numbers = {};
```

## Подсказка 3: Уникальность элементов
При создании Set автоматически удаляет дубликаты:
```dart
var numbers = {1, 2, 3, 2, 4, 1, 5};
print(numbers); // {1, 2, 3, 4, 5} - только уникальные
```

## Подсказка 4: Основные свойства и методы
```dart
var fruits = {'яблоко', 'банан', 'апельсин'};

// Количество элементов
print(fruits.length); // 3

// Проверка наличия элемента
print(fruits.contains('яблоко')); // true
print(fruits.contains('груша')); // false

// Добавление элемента
fruits.add('манго'); // добавит 'манго'
fruits.add('яблоко'); // не добавит - уже есть
```

## Подсказка 5: Добавление дубликатов
Когда вы пытаетесь добавить элемент, который уже есть в Set:
```dart
var colors = {'красный', 'синий'};
colors.add('зеленый'); // добавится
colors.add('красный'); // не добавится, но и ошибки не будет
print(colors); // {красный, синий, зеленый}
```

## Частые ошибки

### Ошибка 1: Попытка создать пустой Set с var
```dart
// НЕПРАВИЛЬНО - это создаст Map, а не Set!
var emptySet = {};

// ПРАВИЛЬНО
var emptySet = <String>{};
Set<int> emptySet = {};
```

### Ошибка 2: Ожидание определенного порядка
```dart
// Set не гарантирует порядок элементов
var numbers = {3, 1, 2};
print(numbers); // может быть {1, 2, 3} или другой порядок
```

## Дополнительные примеры

### Пример 1: Создание множества с дубликатами
```dart
var cities = {'Москва', 'Санкт-Петербург', 'Москва', 'Казань', 'Москва'};
print(cities); // {Москва, Санкт-Петербург, Казань}
print('Количество городов: ${cities.length}'); // 3
```

### Пример 2: Проверка и добавление
```dart
var animals = {'кот', 'собака', 'птица'};

if (animals.contains('кот')) {
  print('Кот уже в списке');
}

animals.add('хомяк');
print('Животных: ${animals.length}'); // 4
```

### Пример 3: Множество чисел
```dart
var scores = {100, 95, 100, 87, 95, 92};
print('Уникальные оценки: $scores');
print('Всего: ${scores.length} уникальных оценок');
```
