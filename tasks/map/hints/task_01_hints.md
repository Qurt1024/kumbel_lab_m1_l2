# Подсказки к Задаче 1: Создание первого словаря Map

## Подсказка 1: Что такое Map
Map (словарь) - это коллекция пар "ключ-значение", где каждый ключ уникален:
```dart
var person = {'name': 'Иван', 'age': 20};
```

## Подсказка 2: Создание Map с разными типами значений
Map может хранить значения разных типов:
```dart
var info = {
  'text': 'Строка',      // String
  'number': 42,          // int
  'decimal': 3.14,       // double
  'flag': true           // bool
};
```

## Подсказка 3: Доступ к значениям по ключу
Чтобы получить значение из Map, используйте квадратные скобки:
```dart
var city = person['city'];    // Получить значение
print('Город: $city');
```

## Подсказка 4: Получение ключей и значений
Map предоставляет специальные свойства:
```dart
var keys = person.keys;       // Все ключи
var values = person.values;   // Все значения
var length = person.length;   // Количество пар
```

## Подсказка 5: Порядок действий
1. Создайте Map с 4 парами "ключ-значение"
2. Выведите весь Map целиком
3. Выведите каждое значение отдельно, обращаясь по ключу
4. Выведите коллекцию ключей через .keys
5. Выведите коллекцию значений через .values
6. Выведите длину Map через .length

## Пример работы с Map
```dart
var book = {
  'title': 'Война и мир',
  'author': 'Толстой',
  'year': 1869,
  'isAvailable': true
};

print('Книга: $book');
print('Название: ${book['title']}');
print('Ключи: ${book.keys}');
print('Значения: ${book.values}');
print('Полей: ${book.length}');
```

## Частые ошибки
- Забыть кавычки у ключей-строк: `{name: 'Иван'}` - ОШИБКА, правильно: `{'name': 'Иван'}`
- Использовать круглые скобки вместо квадратных: `person('name')` - ОШИБКА, правильно: `person['name']`
- Забыть символ $ при интерполяции: `print('Имя: name')` - выведет "name" вместо значения
