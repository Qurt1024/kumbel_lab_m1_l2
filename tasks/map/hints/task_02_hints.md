# Подсказки к Задаче 2: Добавление и изменение элементов Map

## Подсказка 1: Создание пустого типизированного Map
Для создания пустого Map с указанием типов используйте:
```dart
var scores = <String, int>{};
// или
Map<String, int> scores = {};
```

## Подсказка 2: Добавление элементов в Map
Добавление работает через присваивание по ключу:
```dart
scores['Иван'] = 100;
scores['Мария'] = 150;
```

## Подсказка 3: Изменение существующих значений
Изменение работает так же, как добавление:
```dart
scores['Иван'] = 180;  // Перезаписывает старое значение
```

## Подсказка 4: Увеличение значения
Чтобы увеличить существующее значение:
```dart
// Получаем текущее значение, добавляем 50, сохраняем обратно
scores['Мария'] = scores['Мария']! + 50;

// Восклицательный знак ! говорит: "Я уверен, что значение есть"
```

## Подсказка 5: Порядок действий
1. Создайте пустой Map с типами <String, int>
2. Добавьте три пары ключ-значение
3. Выведите текущее состояние
4. Измените значение одного ключа напрямую
5. Увеличите значение другого ключа на число
6. Выведите финальное состояние

## Пример с выводом изменений
```dart
var points = <String, int>{};
points['Alex'] = 50;
print('Alex: ${points['Alex']} баллов');

points['Alex'] = 100;
print('Alex: ${points['Alex']} баллов (обновлено)');

points['Alex'] = points['Alex']! + 25;
print('Alex: ${points['Alex']} баллов (+25)');
```

## Частые ошибки
- Забыть восклицательный знак при увеличении: `scores['Name'] + 50` - ОШИБКА
- Пытаться добавить значение неправильного типа: `scores['Name'] = '100'` - ОШИБКА (это String, нужен int)
- Не показать изменения: выводите промежуточные состояния для наглядности
