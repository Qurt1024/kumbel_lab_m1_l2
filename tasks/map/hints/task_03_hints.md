# Подсказки к Задаче 3: Удаление элементов из Map

## Подсказка 1: Метод remove()
Для удаления элемента по ключу используйте метод remove():
```dart
contacts.remove('Работа');  // Удаляет пару с ключом 'Работа'
```

## Подсказка 2: Метод clear()
Для полной очистки Map (в этой задаче не нужен, но полезно знать):
```dart
contacts.clear();  // Удаляет все элементы
```

## Подсказка 3: Проверка наличия ключа
Перед удалением можно проверить наличие ключа:
```dart
if (contacts.containsKey('Работа')) {
  contacts.remove('Работа');
}
```

## Подсказка 4: Вывод всех контактов
Чтобы вывести все контакты красиво:
```dart
contacts.forEach((name, phone) {
  print('$name: $phone');
});
```

## Подсказка 5: Порядок действий
1. Создайте Map с 5 контактами
2. Выведите все контакты и их количество
3. Удалите первый контакт и сообщите об этом
4. Удалите второй контакт и сообщите об этом
5. Выведите обновленный список
6. Выведите новое количество контактов

## Пример работы с удалением
```dart
var items = {
  'яблоко': 5,
  'банан': 3,
  'апельсин': 7
};

print('До удаления: ${items.length} товаров');
items.remove('банан');
print('Удален: банан');
print('После удаления: ${items.length} товара');
print('Остались: ${items.keys}');
```

## Частые ошибки
- Забыть кавычки у ключа: `remove(Работа)` - ОШИБКА, правильно: `remove('Работа')`
- Пытаться удалить несуществующий ключ - не ошибка, но ничего не произойдет
- Не обновить вывод количества после удаления
- Использовать delete вместо remove: `contacts.delete()` - такого метода нет!
