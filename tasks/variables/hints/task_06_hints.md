# Подсказки к Задаче 6: Изменение значений переменных

## Подсказка 1: Изменение переменной

Полная форма:
```dart
balance = balance + 500;
```

Короткая форма:
```dart
balance += 500;
```

## Подсказка 2: Все арифметические операторы присваивания

| Оператор | Полная форма | Короткая форма |
|----------|--------------|----------------|
| Сложение | `x = x + 5` | `x += 5` |
| Вычитание | `x = x - 3` | `x -= 3` |
| Умножение | `x = x * 2` | `x *= 2` |
| Деление | `x = x / 4` | `x /= 4` |
| Целочисленное деление | `x = x ~/ 2` | `x ~/= 2` |

## Подсказка 3: Увеличение счетчика на 1

Способ 1:
```dart
transactions = transactions + 1;
```

Способ 2:
```dart
transactions += 1;
```

Способ 3:
```dart
transactions++;
```

Все три способа делают одно и то же!

## Подсказка 4: Пример операций с балансом

```dart
var balance = 1000;

// Пополнение
balance += 500;  // balance = 1500

// Покупка
balance -= 200;  // balance = 1300

// Удвоение
balance *= 2;    // balance = 2600
```

## Подсказка 5: Отслеживание операций

```dart
var balance = 1000;
var transactions = 0;

balance += 500;
transactions++;

print('Баланс: $balance');
print('Операций: $transactions');
```
