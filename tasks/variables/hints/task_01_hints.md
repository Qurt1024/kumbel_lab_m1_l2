# Подсказки к Задаче 1: Создание первой переменной

## Подсказка 1: Создание переменной
Для создания переменной используйте ключевое слово `var`:
```dart
var имяПеременной = значение;
```

## Подсказка 2: Типы значений
- Текст (строки) заключается в кавычки: `'Привет'` или `"Привет"`
- Числа пишутся без кавычек: `42` или `3.14`

## Подсказка 3: Вывод текста
Для вывода текста на экран используйте функцию `print()`:
```dart
print('Текст для вывода');
```

## Подсказка 4: Интерполяция строк
Чтобы вставить значение переменной в текст, используйте знак `$`:
```dart
var name = 'Иван';
print('Привет, $name!'); // Выведет: Привет, Иван!
```

## Подсказка 5: Пример
```dart
var city = 'Москва';
var temperature = 15;
print('Город: $city, температура: $temperature');
```
