# Подсказки к Задаче 4: Неизменяемые переменные с final

## Подсказка 1: Что такое final
`final` используется для переменных, которые:
- Устанавливаются один раз
- Не могут быть изменены после присваивания
- Значение может быть вычислено во время выполнения (в отличие от const)

## Подсказка 2: Синтаксис final
```dart
final имяПеременной = значение;
```

Пример:
```dart
final currentYear = 2025;
final birthYear = 2005;
```

## Подсказка 3: Разница между const и final

| const | final |
|-------|-------|
| Значение должно быть известно ДО запуска | Значение может быть вычислено при запуске |
| Константа времени компиляции | Константа времени выполнения |
| `const pi = 3.14159;` | `final time = DateTime.now();` |

## Подсказка 4: Вычитание
Для вычитания используйте оператор `-`:
```dart
var age = 2025 - 2005;  // 20
```

## Подсказка 5: Пример
```dart
final currentYear = 2025;
final birthYear = 2000;
var age = currentYear - birthYear;  // age можно изменить
print('Возраст: $age');
```

## Важно!
Попытка изменить final переменную вызовет ошибку:
```dart
final name = 'Иван';
name = 'Петр'; // ОШИБКА!
```
