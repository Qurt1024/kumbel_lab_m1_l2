# Подсказки к Задаче 5: Различия между var, final и const

## Подсказка 1: Сравнение var, final и const

| Тип | Можно изменять? | Когда устанавливается значение? |
|-----|-----------------|----------------------------------|
| `var` | ✅ Да | Когда угодно |
| `final` | ❌ Нет | Один раз, при выполнении |
| `const` | ❌ Нет | До запуска программы |

## Подсказка 2: Примеры использования

```dart
// var - изменяемая переменная
var counter = 0;
counter = 1;     // ✅ Можно
counter = 2;     // ✅ Можно

// final - устанавливается один раз
final startTime = 12345;
startTime = 54321;  // ❌ ОШИБКА!

// const - константа времени компиляции
const maxAttempts = 3;
maxAttempts = 5;    // ❌ ОШИБКА!
```

## Подсказка 3: Увеличение значения переменной

Способ 1:
```dart
counter = counter + 1;
```

Способ 2 (короче):
```dart
counter += 1;
```

Способ 3 (еще короче):
```dart
counter++;
```

## Подсказка 4: Когда что использовать

- **var**: когда значение будет меняться (счетчики, накопители)
- **final**: когда значение вычисляется при запуске и не меняется (время старта, ID сессии)
- **const**: когда значение известно заранее и никогда не меняется (настройки, лимиты)

## Подсказка 5: Получение текущего времени
```dart
final now = DateTime.now().millisecondsSinceEpoch;
```

Или просто используйте число:
```dart
final startTime = 12345;
```
