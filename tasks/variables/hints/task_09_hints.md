# Подсказки к Задаче 9: Область видимости переменных

## Подсказка 1: Что такое блок кода

Блок кода - это код, заключенный в фигурные скобки `{ }`:
```dart
{
  // Код внутри блока
  var localVariable = 10;
}
```

## Подсказка 2: Область видимости (scope)

Переменные, объявленные внутри блока, доступны только в этом блоке:
```dart
var global = 'Доступна везде';

{
  var local = 'Доступна только здесь';
  print(global);  // ✅ Работает
  print(local);   // ✅ Работает
}

print(global);  // ✅ Работает
print(local);   // ❌ ОШИБКА! local не существует здесь
```

## Подсказка 3: Переменные с одинаковыми именами в разных блоках

Это допустимо! Каждый блок создает свою область видимости:
```dart
{
  var score = 100;
  print(score);  // 100
}

{
  var score = 200;  // Другая переменная!
  print(score);  // 200
}
```

## Подсказка 4: Доступ к внешним переменным

Переменные из внешней области доступны внутри блока:
```dart
var totalScore = 0;

{
  var levelScore = 100;
  totalScore += levelScore;  // Можем изменять внешнюю переменную
}

print(totalScore);  // 100
```

## Подсказка 5: Структура решения

```dart
void main() {
  var totalScore = 0;  // Глобальная для main

  // Уровень 1
  {
    var levelScore = 100;
    totalScore += levelScore;
    print('Уровень 1: $levelScore очков');
  }

  // Уровень 2
  {
    var levelScore = 150;  // Новая переменная!
    totalScore += levelScore;
    print('Уровень 2: $levelScore очков');
  }

  print('Итого: $totalScore');
}
```

## Важно понять!

1. Переменная внутри `{ }` **умирает** после закрывающей скобки
2. В разных блоках можно использовать **одинаковые имена**
3. Внешние переменные **доступны** внутри блоков
4. Внутренние переменные **недоступны** снаружи блока
