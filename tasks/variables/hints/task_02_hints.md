# Подсказки к Задаче 2: Использование var для разных типов

## Подсказка 1: Автоматическое определение типа
`var` автоматически определяет тип переменной на основе присвоенного значения:
- `var city = 'Москва';` создаст переменную типа String (текст)
- `var age = 20;` создаст переменную типа int (целое число)
- `var price = 99.99;` создаст переменную типа double (дробное число)
- `var isActive = true;` создаст переменную типа bool (логическое значение)

## Подсказка 2: Логический тип bool
Логический тип bool может иметь только два значения:
- `true` (истина, да)
- `false` (ложь, нет)

## Подсказка 3: Проверка типа переменной
Вы можете проверить тип переменной используя `.runtimeType`:
```dart
var name = 'Иван';
print(name.runtimeType); // Выведет: String
```

## Подсказка 4: Пример создания разных типов
```dart
var productName = 'Ноутбук';     // String
var quantity = 5;                 // int
var price = 49999.99;            // double
var inStock = true;              // bool
```
