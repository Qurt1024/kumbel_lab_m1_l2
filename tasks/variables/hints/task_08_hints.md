# Подсказки к Задаче 8: Множественное объявление переменных

## Подсказка 1: Множественное объявление

Можно объявить несколько переменных одного типа в одной строке:
```dart
int red = 255, green = 100, blue = 50;
```

Это эквивалентно:
```dart
int red = 255;
int green = 100;
int blue = 50;
```

## Подсказка 2: Объявление без инициализации

Можно объявить переменные без начального значения:
```dart
int x, y, z;
x = 10;
y = 20;
z = 30;
```

## Подсказка 3: Смешанное объявление

Можно комбинировать инициализированные и неинициализированные переменные:
```dart
int a = 1, b = 2, c;
c = 3;
```

## Подсказка 4: RGB цвета

RGB (Red, Green, Blue) - модель цвета, где каждый канал имеет значение от 0 до 255:
- (255, 0, 0) - красный
- (0, 255, 0) - зеленый
- (0, 0, 255) - синий
- (255, 255, 0) - желтый
- (255, 100, 50) - оранжевый

## Подсказка 5: Координаты точки в 3D пространстве

```dart
double x = 10.5, y = 20.3, z = 15.7;
print('Координаты: ($x, $y, $z)');
```

## Подсказка 6: Пример использования

```dart
// Цвет
int red = 255, green = 100, blue = 50;
String colorName = 'Оранжевый';
print('Цвет: $colorName');
print('RGB: ($red, $green, $blue)');

// Координаты
double x = 10.5, y = 20.3, z = 15.7;
String pointName = 'A';
print('\nТочка: $pointName');
print('Координаты: ($x, $y, $z)');
```

## Когда использовать

Множественное объявление удобно когда:
- Переменные связаны логически (координаты, RGB компоненты)
- Все переменные имеют один тип
- Нужно сделать код компактнее
