# Подсказки к Задаче 3: Константы с const

## Подсказка 1: Что такое const
`const` используется для создания константы - значения, которое:
- Известно ДО запуска программы (во время компиляции)
- НИКОГДА не изменится во время выполнения

## Подсказка 2: Синтаксис const
```dart
const имяКонстанты = значение;
```

Пример:
```dart
const pi = 3.14159;
const maxUsers = 100;
const appVersion = '1.0.0';
```

## Подсказка 3: Когда использовать const
Используйте `const` для:
- Математических константы (π, e)
- Фиксированных настроек (максимальное количество, размеры)
- Неизменяемых строк (названия, версии)

## Подсказка 4: Математические операции
Для умножения используйте оператор `*`:
```dart
var result = 2 * 5;  // 10
```

## Подсказка 5: Формула длины окружности
Длина окружности = 2 × π × радиус
```dart
const pi = 3.14159;
var radius = 5;
var circumference = 2 * pi * radius;
```

## Важно!
Попытка изменить константу вызовет ошибку компиляции:
```dart
const pi = 3.14159;
pi = 3.14; // ОШИБКА!
```
