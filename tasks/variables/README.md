# Задачи по теме "Переменные" (Variables)

Эта папка содержит 10 задач для изучения переменных в Dart.

## Структура

```
variables/
├── task_01_easy.dart       # Задача 1 (легкая)
├── task_02_easy.dart       # Задача 2 (легкая)
├── ...
├── task_10_hard.dart       # Задача 10 (сложная)
├── hints/                  # Подсказки к задачам
│   ├── task_01_hints.md
│   ├── task_02_hints.md
│   └── ...
└── README.md              # Этот файл
```

## Решения

Решения находятся в отдельной папке:
```
solutions/variables/
├── task_01_solution.dart
├── task_02_solution.dart
└── ...
```

## Уровни сложности

- **Легкие (Easy):** задачи 1-4
  - Основы создания переменных
  - Использование var, const, final

- **Средние (Medium):** задачи 5-8
  - Различия между типами переменных
  - Изменение значений
  - Типизированные переменные
  - Множественное объявление

- **Сложные (Hard):** задачи 9-10
  - Область видимости
  - Late переменные

## Как работать с задачами

1. **Читайте описание задачи** в файле `.dart`
2. **Пишите код** в функции `main()`
3. **Запускайте программу:** `dart variables/task_01_easy.dart`
4. **Если нужна помощь** - смотрите файл подсказок в папке `hints/`
5. **Проверьте решение** в папке `solutions/`

## Подсказки

Если застряли, откройте соответствующий файл в папке `hints/`:
- `task_01_hints.md` - подсказки к первой задаче
- `task_02_hints.md` - подсказки ко второй задаче
- и т.д.

Подсказки содержат:
- Примеры синтаксиса
- Пошаговые инструкции
- Разъяснения концепций

## Порядок изучения

Рекомендуется решать задачи по порядку:
1. Начните с легких задач (1-4)
2. Переходите к средним (5-8)
3. Завершите сложными (9-10)

Удачи в изучении Dart! 🚀
