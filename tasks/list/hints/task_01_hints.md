# Подсказки к Задаче 1: Создание первого списка

## Описание
Список (List) - это упорядоченная коллекция элементов. Каждый элемент имеет свой индекс, начиная с 0.

## Пошаговое решение

| Шаг | Что нужно сделать | Синтаксис |
|-----|-------------------|-----------|
| 1 | Создать список со значениями | `var fruits = ['яблоко', 'банан', ...]` |
| 2 | Вывести весь список | `print('Список: $fruits')` |
| 3 | Получить элемент по индексу | `fruits[0]` - первый элемент |
| 4 | Получить последний элемент | `fruits[4]` - элемент с индексом 4 |
| 5 | Получить длину списка | `fruits.length` |

## Синтаксис создания списков

```dart
// Способ 1: С указанием типа
List<String> fruits = ['яблоко', 'банан', 'апельсин'];

// Способ 2: С автоматическим определением типа
var fruits = ['яблоко', 'банан', 'апельсин'];

// Способ 3: Пустой список
var emptyList = <String>[];
```

## Доступ к элементам

```dart
var fruits = ['яблоко', 'банан', 'апельсин'];

// По индексу
print(fruits[0]);  // яблоко (первый элемент)
print(fruits[1]);  // банан (второй элемент)
print(fruits[2]);  // апельсин (третий элемент)

// Длина списка
print(fruits.length);  // 3
```

## Частые ошибки

1. **Забыли, что индексация начинается с 0**
   ```dart
   // Неправильно
   print(fruits[1]);  // Это второй элемент, не первый!

   // Правильно
   print(fruits[0]);  // Это первый элемент
   ```

2. **Выход за границы списка**
   ```dart
   var fruits = ['яблоко', 'банан'];
   print(fruits[2]);  // ОШИБКА! Индекс 2 не существует

   // Всегда проверяйте длину
   print(fruits.length);  // 2 элемента (индексы 0 и 1)
   ```

3. **Неправильный синтаксис создания списка**
   ```dart
   // Неправильно
   var fruits = ['яблоко', 'банан',];  // Лишняя запятая в конце

   // Правильно
   var fruits = ['яблоко', 'банан'];
   ```

## Дополнительные примеры

```dart
// Список чисел
var numbers = [1, 2, 3, 4, 5];
print('Первое число: ${numbers[0]}');
print('Последнее число: ${numbers[4]}');
print('Всего чисел: ${numbers.length}');

// Список городов
var cities = ['Москва', 'Санкт-Петербург', 'Казань'];
print('Первый город: ${cities[0]}');
print('Третий город: ${cities[2]}');
print('Количество городов: ${cities.length}');
```

## Полезная информация

- Индексы в списке всегда начинаются с 0
- Последний элемент имеет индекс `length - 1`
- Используйте квадратные скобки `[]` для доступа к элементам
- Списки могут содержать элементы одного типа
