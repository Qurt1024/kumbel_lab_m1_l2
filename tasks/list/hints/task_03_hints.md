# Подсказки к Задаче 3: Изменение элементов списка

## Описание
Элементы списка можно изменять и удалять. Для изменения используется доступ по индексу, для удаления - методы remove() и removeAt().

## Пошаговое решение

| Шаг | Что нужно сделать | Синтаксис |
|-----|-------------------|-----------|
| 1 | Создать список с элементами | `var colors = ['красный', ...]` |
| 2 | Изменить элемент по индексу | `colors[1] = 'новый цвет'` |
| 3 | Удалить элемент по значению | `colors.remove('синий')` |
| 4 | Удалить элемент по индексу | `colors.removeAt(0)` |
| 5 | Вывести результаты | `print(colors)` |

## Синтаксис изменения элементов

```dart
var colors = ['красный', 'зелёный', 'синий'];

// Изменение элемента по индексу
colors[0] = 'оранжевый';  // Заменяем первый элемент
colors[1] = 'жёлтый';     // Заменяем второй элемент

// Изменение последнего элемента
colors[colors.length - 1] = 'фиолетовый';

print(colors);  // [оранжевый, жёлтый, фиолетовый]
```

## Методы удаления элементов

```dart
var list = ['A', 'B', 'C', 'D', 'E'];

// remove() - удаляет первое вхождение элемента по значению
list.remove('C');  // Удаляет 'C'
// Результат: ['A', 'B', 'D', 'E']

// removeAt() - удаляет элемент по индексу
list.removeAt(0);  // Удаляет первый элемент
// Результат: ['B', 'D', 'E']

// removeLast() - удаляет последний элемент
list.removeLast();  // Удаляет 'E'
// Результат: ['B', 'D']

// removeWhere() - удаляет элементы по условию
list.removeWhere((item) => item == 'D');
// Результат: ['B']

// clear() - удаляет все элементы
list.clear();  // Список становится пустым
```

## Работа с индексами

```dart
var colors = ['красный', 'зелёный', 'синий', 'жёлтый', 'чёрный'];

// Первый элемент (индекс 0)
colors[0] = 'белый';

// Второй элемент (индекс 1)
colors[1] = 'серый';

// Последний элемент
colors[colors.length - 1] = 'розовый';

// Проверка длины перед изменением
if (colors.length > 2) {
  colors[2] = 'голубой';
}
```

## Частые ошибки

1. **Выход за границы при изменении**
   ```dart
   var colors = ['красный', 'зелёный'];
   colors[5] = 'синий';  // ОШИБКА! Индекс 5 не существует

   // Правильно - используйте add()
   colors.add('синий');  // OK
   ```

2. **Удаление несуществующего элемента**
   ```dart
   var colors = ['красный', 'зелёный'];
   colors.remove('синий');  // Ничего не произойдет (нет ошибки)

   // Проверка наличия элемента
   if (colors.contains('синий')) {
     colors.remove('синий');
   }
   ```

3. **Удаление по неправильному индексу**
   ```dart
   var colors = ['красный', 'зелёный'];
   colors.removeAt(5);  // ОШИБКА! Индекс 5 не существует

   // Правильно - проверяйте границы
   if (colors.length > 1) {
     colors.removeAt(1);  // OK
   }
   ```

4. **Изменение константного списка**
   ```dart
   var colors = const ['красный', 'зелёный'];
   colors[0] = 'синий';  // ОШИБКА! Нельзя изменять const

   // Правильно
   var colors = ['красный', 'зелёный'];
   colors[0] = 'синий';  // OK
   ```

## Дополнительные примеры

```dart
// Управление списком задач
var tasks = ['Задача 1', 'Задача 2', 'Задача 3', 'Задача 4'];

print('Исходные задачи: $tasks');

// Изменяем вторую задачу
tasks[1] = 'Обновленная задача 2';
print('После изменения: $tasks');

// Удаляем конкретную задачу
tasks.remove('Задача 3');
print('После удаления по значению: $tasks');

// Удаляем первую задачу
tasks.removeAt(0);
print('После удаления по индексу: $tasks');

// Удаляем последнюю задачу
tasks.removeLast();
print('Финальный список: $tasks');
```

## Различия между remove() и removeAt()

```dart
var numbers = [1, 2, 3, 2, 4];

// remove() - удаляет по значению (первое вхождение)
numbers.remove(2);  // Удаляет первую двойку
print(numbers);  // [1, 3, 2, 4]

// removeAt() - удаляет по индексу
numbers.removeAt(2);  // Удаляет элемент с индексом 2
print(numbers);  // [1, 3, 4]
```

## Полезная информация

- Изменение: `list[index] = newValue`
- Удаление по значению: `list.remove(value)` - удаляет первое вхождение
- Удаление по индексу: `list.removeAt(index)` - удаляет конкретную позицию
- После удаления индексы следующих элементов сдвигаются
- Всегда проверяйте границы списка перед операциями
