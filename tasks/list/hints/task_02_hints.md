# Подсказки к Задаче 2: Добавление элементов в список

## Описание
Списки в Dart являются динамическими - можно добавлять и удалять элементы после создания списка.

## Пошаговое решение

| Шаг | Что нужно сделать | Синтаксис |
|-----|-------------------|-----------|
| 1 | Создать пустой список | `var tasks = <String>[]` |
| 2 | Добавить один элемент | `tasks.add('задача')` |
| 3 | Добавить несколько элементов | `tasks.addAll(['задача1', 'задача2'])` |
| 4 | Вывести список с индексами | Использовать цикл for |
| 5 | Показать длину списка | `tasks.length` |

## Синтаксис работы с добавлением

```dart
// Создание пустого списка
var tasks = <String>[];

// Добавление одного элемента
tasks.add('Первая задача');

// Добавление нескольких элементов
tasks.addAll(['Вторая задача', 'Третья задача']);

// Вывод всех элементов
print(tasks);  // [Первая задача, Вторая задача, Третья задача]
```

## Методы добавления элементов

```dart
var list = <String>[];

// add() - добавляет один элемент в конец
list.add('элемент 1');

// addAll() - добавляет несколько элементов из другого списка
list.addAll(['элемент 2', 'элемент 3']);

// insert() - вставляет элемент на определенную позицию
list.insert(0, 'первый элемент');

// insertAll() - вставляет несколько элементов
list.insertAll(1, ['второй', 'третий']);
```

## Форматированный вывод

```dart
var tasks = ['Задача 1', 'Задача 2', 'Задача 3'];

// Способ 1: С помощью цикла for
for (var i = 0; i < tasks.length; i++) {
  print('${i + 1}. ${tasks[i]}');
}

// Способ 2: С помощью forEach
var index = 1;
tasks.forEach((task) {
  print('$index. $task');
  index++;
});

// Способ 3: С помощью цикла for-in
var counter = 1;
for (var task in tasks) {
  print('$counter. $task');
  counter++;
}
```

## Частые ошибки

1. **Создание неизменяемого списка**
   ```dart
   // Неправильно - константный список нельзя изменять
   var tasks = const ['задача 1'];
   tasks.add('задача 2');  // ОШИБКА!

   // Правильно - обычный список
   var tasks = ['задача 1'];
   tasks.add('задача 2');  // OK
   ```

2. **Неправильный тип элементов**
   ```dart
   // Неправильно
   var numbers = <int>[];
   numbers.add('текст');  // ОШИБКА! Ожидается int

   // Правильно
   var numbers = <int>[];
   numbers.add(42);  // OK
   ```

3. **Забыли преобразовать в список**
   ```dart
   // addAll() принимает Iterable
   var tasks = ['задача 1'];
   tasks.addAll('задача 2');  // ОШИБКА! Нужен список

   // Правильно
   tasks.addAll(['задача 2']);  // OK
   ```

## Дополнительные примеры

```dart
// Список покупок
var shopping = <String>[];
shopping.add('Хлеб');
shopping.add('Молоко');
shopping.add('Яйца');
print('Список покупок: $shopping');
print('Нужно купить ${shopping.length} товаров');

// Добавление нескольких товаров сразу
var moreShopping = ['Сыр', 'Масло'];
shopping.addAll(moreShopping);
print('Обновленный список: $shopping');

// Красивый вывод
print('\nСписок покупок:');
for (var i = 0; i < shopping.length; i++) {
  print('${i + 1}. ${shopping[i]}');
}
```

## Полезная информация

- `add()` добавляет один элемент
- `addAll()` добавляет несколько элементов из коллекции
- Элементы всегда добавляются в конец списка
- Пустой список создается через `<Type>[]` или `[]`
- После добавления элементов длина списка автоматически увеличивается
