# Подсказки к Задаче 2: Оператор проверки на null (??)

## Подсказка 1: Оператор ?? (null-coalescing)
Оператор ?? позволяет задать значение по умолчанию, если переменная равна null:
```dart
значение ?? значениеПоУмолчанию
```

## Подсказка 2: Как работает ??
- Если левое значение НЕ null, вернется левое значение
- Если левое значение null, вернется правое значение

```dart
String? name = null;
String displayName = name ?? 'Гость';
// displayName будет 'Гость'
```

## Подсказка 3: Использование с разными типами
Оператор ?? работает с любыми типами:
```dart
int? age = null;
int defaultAge = age ?? 18;

String? city = 'Москва';
String result = city ?? 'Неизвестно';  // result будет 'Москва'
```

## Подсказка 4: Присвоение результата
Результат выражения с ?? можно присвоить переменной:
```dart
String? userName = null;
var display = userName ?? 'Аноним';
print(display);  // Аноним
```

## Подсказка 5: Изменение значения
После изменения nullable переменной, результат ?? тоже изменится:
```dart
String? text = null;
print(text ?? 'Пусто');  // Пусто

text = 'Заполнено';
print(text ?? 'Пусто');  // Заполнено
```

## Подсказка 6: Пример с числами
```dart
int? score = null;
int finalScore = score ?? 0;
print('Очки: $finalScore');  // Очки: 0

score = 100;
finalScore = score ?? 0;
print('Очки: $finalScore');  // Очки: 100
```
