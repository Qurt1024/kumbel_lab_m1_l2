# Подсказки к Задаче 2: Работа с числами

## Краткое описание
В Dart существует два типа для работы с числами: int (целые числа) и double (числа с дробной частью). Важно понимать разницу между разными операциями деления.

## Пошаговое решение

| Шаг | Действие | Что использовать |
|-----|----------|------------------|
| 1 | Создать переменную для количества яблок | `int apples = 10;` |
| 2 | Создать переменную для количества людей | `int people = 3;` |
| 3 | Вычислить целочисленное деление | `int result = apples ~/ people;` |
| 4 | Вычислить остаток от деления | `int remainder = apples % people;` |
| 5 | Вычислить точное деление | `double precise = apples / people;` |
| 6 | Вывести все результаты с пояснениями | Использовать `print()` |

## Синтаксис и примеры

### Операции с числами

```dart
int a = 10;
int b = 3;

// Обычное деление (результат double)
double result1 = a / b;  // 3.3333333333333335

// Целочисленное деление (результат int)
int result2 = a ~/ b;  // 3

// Остаток от деления
int result3 = a % b;  // 1

// Умножение
int result4 = a * b;  // 30
```

### Разница между / и ~/

```dart
// Оператор / всегда возвращает double
print(10 / 3);   // 3.3333333333333335
print(10 / 2);   // 5.0 (double, не int!)

// Оператор ~/ возвращает int (отбрасывает дробную часть)
print(10 ~/ 3);  // 3
print(10 ~/ 2);  // 5
```

## Частые ошибки

1. **Использование / вместо ~/ для целых чисел**
   ```dart
   int each = 10 / 3;  // ОШИБКА! Результат деления / - это double
   int each = 10 ~/ 3;  // Правильно, результат 3
   ```

2. **Путаница между ~/ и %**
   ```dart
   // ~/ дает целую часть
   print(10 ~/ 3);  // 3 (сколько раз 3 помещается в 10)

   // % дает остаток
   print(10 % 3);   // 1 (что остается после деления)
   ```

3. **Неправильный тип переменной**
   ```dart
   int result = 10 / 3;  // ОШИБКА! Нельзя присвоить double в int
   double result = 10 / 3;  // Правильно
   ```

## Дополнительные примеры

```dart
// Пример: делим пиццу на друзей
int pizzaSlices = 16;
int friends = 5;

int slicesPerPerson = pizzaSlices ~/ friends;  // 3
int leftover = pizzaSlices % friends;          // 1
double exact = pizzaSlices / friends;          // 3.2

print('Каждый получит: $slicesPerPerson кусков');
print('Останется: $leftover кусок');
print('Точно: $exact кусков на человека');
```
