# Подсказки к Задаче 6: Строковая интерполяция

## Краткое описание
Интерполяция - это мощный способ вставки значений переменных и вычисления выражений прямо внутри строки. Это намного удобнее, чем склеивать строки через оператор +.

## Пошаговое решение

| Шаг | Действие | Что использовать |
|-----|----------|------------------|
| 1 | Создать переменные товара | Объявить String, double, int переменные |
| 2 | Вычислить сумму без скидки | `price * quantity` |
| 3 | Вычислить размер скидки | `totalPrice * discount` |
| 4 | Вычислить итоговую сумму | `totalPrice - discountAmount` |
| 5 | Вывести чек с интерполяцией | `'Товар: $productName'` |
| 6 | Использовать вычисления в строке | `'Сумма: ${price * quantity}'` |

## Синтаксис и примеры

### Простая интерполяция с $

```dart
String name = 'Анна';
int age = 25;

print('Меня зовут $name');  // Меня зовут Анна
print('Мне $age лет');       // Мне 25 лет
```

### Интерполяция с выражениями ${}

```dart
int a = 10;
int b = 20;

// Вычисления внутри строки
print('Сумма: ${a + b}');         // Сумма: 30
print('Произведение: ${a * b}');  // Произведение: 200

// Вызов методов
String text = 'Привет';
print('Длина: ${text.length}');   // Длина: 6
```

### Когда использовать ${} вместо $

```dart
String name = 'Иван';

// Просто переменная - можно без {}
print('Привет, $name!');

// Выражение или вызов метода - нужны {}
print('Привет, ${name.toUpperCase()}!');  // Привет, ИВАН!

// Вычисления - нужны {}
int age = 25;
print('Через 5 лет: ${age + 5}');
```

## Частые ошибки

1. **Забыть $ перед переменной**
   ```dart
   String name = 'Иван';
   print('Привет, name');   // Выведет: Привет, name
   print('Привет, $name');  // Выведет: Привет, Иван
   ```

2. **Использовать $ вместо ${} для выражений**
   ```dart
   int price = 100;
   int qty = 2;
   print('Сумма: $price * qty');    // Сумма: 100 * qty (неправильно!)
   print('Сумма: ${price * qty}');  // Сумма: 200 (правильно!)
   ```

3. **Путаница между конкатенацией и интерполяцией**
   ```dart
   // Конкатенация (старый способ)
   String result = 'Имя: ' + name + ', возраст: ' + age.toString();

   // Интерполяция (современный способ)
   String result = 'Имя: $name, возраст: $age';
   ```

4. **Забыть toString() при конкатенации**
   ```dart
   int age = 25;
   String text = 'Возраст: ' + age;  // ОШИБКА!
   String text = 'Возраст: ' + age.toString();  // Правильно для +
   String text = 'Возраст: $age';  // Лучше - интерполяция
   ```

## Дополнительные примеры

### Пример 1: Форматирование чека

```dart
String product = 'Телефон';
int quantity = 2;
double price = 15000.50;
double total = price * quantity;

print('═══════════ ЧЕК ═══════════');
print('Товар: $product');
print('Количество: $quantity шт.');
print('Цена: $price руб.');
print('Итого: $total руб.');
print('══════════════════════════════');
```

### Пример 2: Вычисления в строках

```dart
int a = 10;
int b = 20;

print('$a + $b = ${a + b}');      // 10 + 20 = 30
print('$a * $b = ${a * b}');      // 10 * 20 = 200
print('$b / $a = ${b / a}');      // 20 / 10 = 2.0
```

### Пример 3: Методы в интерполяции

```dart
String name = 'иван';
print('Привет, ${name.toUpperCase()}!');  // Привет, ИВАН!

double price = 1234.567;
print('Цена: ${price.toStringAsFixed(2)} руб.');  // Цена: 1234.57 руб.

String text = 'Dart';
print('Длина слова "$text": ${text.length}');  // Длина слова "Dart": 4
```

### Пример 4: Сложные выражения

```dart
double price = 1000.0;
double discount = 0.15;  // 15%
int quantity = 3;

String receipt = '''
Товар: Ноутбук
Цена: $price руб.
Количество: $quantity шт.
Сумма: ${price * quantity} руб.
Скидка ${discount * 100}%: ${price * quantity * discount} руб.
Итого: ${price * quantity * (1 - discount)} руб.
''';

print(receipt);
```

## Подсказка по форматированию чисел

Для ограничения количества знаков после запятой:

```dart
double value = 123.456789;

// Фиксированное количество знаков
print(value.toStringAsFixed(2));  // 123.46
print(value.toStringAsFixed(0));  // 123

// В интерполяции
print('Цена: ${value.toStringAsFixed(2)} руб.');
```

## Подсказка по многострочным чекам

Используйте тройные кавычки для красивого форматирования:

```dart
String receipt = '''
============== ЧЕК ==============
Товар: $productName
Цена за единицу: $price руб.
Количество: $quantity шт.
Сумма: ${price * quantity} руб.
Скидка $discount%: ${totalDiscount} руб.
===================================
ИТОГО К ОПЛАТЕ: $finalPrice руб.
''';

print(receipt);
```

## Сравнение методов

| Метод | Пример | Когда использовать |
|-------|--------|-------------------|
| Конкатенация | `'Привет ' + name` | Редко, устаревший способ |
| Простая интерполяция | `'Привет $name'` | Для простых переменных |
| Интерполяция с {} | `'Сумма: ${a + b}'` | Для выражений и методов |
