# Подсказки к Задаче 1: Основные типы данных

## Краткое описание
В Dart есть четыре основных типа данных для хранения разной информации. Каждый тип предназначен для определенного вида данных.

## Пошаговое решение

| Шаг | Действие | Что использовать |
|-----|----------|------------------|
| 1 | Объявить переменную для названия книги | `String bookName = 'название';` |
| 2 | Объявить переменную для количества страниц | `int pages = число;` |
| 3 | Объявить переменную для рейтинга | `double rating = число.число;` |
| 4 | Объявить переменную для статуса прочтения | `bool isRead = true/false;` |
| 5 | Вывести информацию о книге | Использовать `print()` с интерполяцией |

## Синтаксис и примеры

### Типы данных в Dart

```dart
// String - для текста
String city = 'Москва';
String country = "Россия";

// int - для целых чисел
int age = 25;
int temperature = -5;

// double - для чисел с дробной частью
double price = 99.99;
double weight = 3.5;

// bool - для логических значений
bool isStudent = true;
bool hasLicense = false;
```

### Интерполяция строк

```dart
String name = 'Иван';
int age = 20;
print('Меня зовут $name, мне $age лет');
// Выведет: Меня зовут Иван, мне 20 лет
```

## Частые ошибки

1. **Путаница между int и double**
   ```dart
   int pages = 350.5;  // ОШИБКА! int не может хранить дробные числа
   double pages = 350.5;  // Правильно
   ```

2. **Забыть кавычки для String**
   ```dart
   String book = Гарри Поттер;  // ОШИБКА!
   String book = 'Гарри Поттер';  // Правильно
   ```

3. **Использование строк вместо bool**
   ```dart
   bool isRead = 'true';  // ОШИБКА! Это строка, а не bool
   bool isRead = true;  // Правильно (без кавычек)
   ```

## Дополнительные примеры

```dart
// Информация о фильме
String movieTitle = 'Начало';
int duration = 148;  // минуты
double rating = 8.8;
bool isWatched = false;

print('Фильм: $movieTitle');
print('Длительность: $duration минут');
print('Рейтинг: $rating из 10');
print('Просмотрено: $isWatched');
```

## Подсказка для форматирования

Для красивого вывода используйте:
- Эмодзи для визуального оформления
- Интерполяцию для вставки значений
- Перенос строк между блоками информации

```dart
print('📖 Информация о книге');
print('Название: $bookName');
print('Страниц: $pages');
```
