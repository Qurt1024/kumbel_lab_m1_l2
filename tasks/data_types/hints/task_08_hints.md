# Подсказки к Задаче 8: Многострочные строки и специальные символы

## Краткое описание
В Dart строки могут быть многострочными (используя тройные кавычки) и содержать специальные символы для форматирования текста. Это полезно для создания читаемого кода с красивым форматированием.

## Пошаговое решение

| Шаг | Действие | Что использовать |
|-----|----------|------------------|
| 1 | Создать многострочную строку | `'''текст в несколько строк'''` |
| 2 | Создать строку с табуляцией | `'текст\tтекст\tтекст'` |
| 3 | Создать строку с переносами | `'строка1\nстрока2\nстрока3'` |
| 4 | Создать строку с кавычками | `'Он сказал: "Привет!"'` или `"Он сказал: \"Привет!\""` |
| 5 | Создать сырую строку | `r'C:\Users\Documents'` |
| 6 | Вывести все строки | Использовать `print()` |

## Синтаксис и примеры

### Многострочные строки

```dart
// Используя тройные одинарные кавычки
String poem1 = '''
Буря мглою небо кроет,
Вихри снежные крутя;
То, как зверь, она завоет,
То заплачет, как дитя
''';

// Используя тройные двойные кавычки
String poem2 = """
У лукоморья дуб зелёный;
Златая цепь на дубе том:
""";

print(poem1);
```

### Специальные символы (escape-последовательности)

```dart
// \n - новая строка
String text1 = 'Первая строка\nВторая строка\nТретья строка';

// \t - табуляция
String text2 = 'Имя\tВозраст\tГород';

// \" - двойная кавычка внутри двойных кавычек
String text3 = "Он сказал: \"Привет!\"";

// \' - одинарная кавычка внутри одинарных кавычек
String text4 = 'Это символ: \'кавычка\'';

// \\ - обратный слэш
String text5 = 'Путь: C:\\Users\\Documents';

print(text1);
print(text2);
```

### Сырые строки (raw strings)

```dart
// Обычная строка - \n создаст перенос
String normal = 'Строка1\nСтрока2';
print(normal);
// Выведет:
// Строка1
// Строка2

// Сырая строка - \n будет просто текстом
String raw = r'Строка1\nСтрока2';
print(raw);
// Выведет: Строка1\nСтрока2

// Полезно для путей Windows
String path = r'C:\Users\Documents\file.txt';
print(path);  // C:\Users\Documents\file.txt
```

## Частые ошибки

1. **Забыть экранировать специальные символы**
   ```dart
   String text = "Он сказал: "Привет!"";  // ОШИБКА!
   String text = "Он сказал: \"Привет!\"";  // Правильно
   // Или использовать другие кавычки
   String text = 'Он сказал: "Привет!"';  // Правильно
   ```

2. **Путаница между \n и \\n**
   ```dart
   // \n создает перенос строки
   print('Строка1\nСтрока2');
   // Выведет:
   // Строка1
   // Строка2

   // \\n выведет текст "\n"
   print('Строка1\\nСтрока2');
   // Выведет: Строка1\nСтрока2
   ```

3. **Использование обычных строк вместо сырых для путей**
   ```dart
   // Неправильно - придется экранировать каждый \
   String path = 'C:\\Users\\Documents\\file.txt';

   // Правильно - используем сырую строку
   String path = r'C:\Users\Documents\file.txt';
   ```

4. **Лишние пробелы в многострочных строках**
   ```dart
   String text = '''
   Строка 1
   Строка 2
   ''';
   // Начнется и закончится с переноса строки!

   // Чтобы избежать:
   String text = '''Строка 1
   Строка 2''';
   ```

## Дополнительные примеры

### Пример 1: Создание таблицы

```dart
String table = '''
Имя\tВозраст\tГород
Иван\t25\tМосква
Мария\t30\tСанкт-Петербург
Петр\t28\tКазань
''';

print(table);
// Выведет:
// Имя    Возраст    Город
// Иван   25         Москва
// ...
```

### Пример 2: Создание меню

```dart
String menu = '''
╔════════════════════╗
║      МЕНЮ          ║
╠════════════════════╣
║ 1. Новая игра      ║
║ 2. Загрузить       ║
║ 3. Настройки       ║
║ 4. Выход           ║
╚════════════════════╝
''';

print(menu);
```

### Пример 3: Работа с кавычками

```dart
// Вариант 1: экранирование
String quote1 = "Он сказал: \"Привет!\"";

// Вариант 2: использование разных кавычек
String quote2 = 'Он сказал: "Привет!"';

// Вариант 3: многострочная строка
String quote3 = '''Он сказал: "Привет!"''';

print(quote1);  // Он сказал: "Привет!"
print(quote2);  // Он сказал: "Привет!"
print(quote3);  // Он сказал: "Привет!"
```

### Пример 4: Пути к файлам

```dart
// Windows - сырая строка
String windowsPath = r'C:\Users\John\Documents\file.txt';

// Unix/Linux - можно обычную
String unixPath = '/home/user/documents/file.txt';

// Или с экранированием
String escapedPath = 'C:\\Users\\John\\Documents\\file.txt';

print(windowsPath);
print(unixPath);
```

## Таблица специальных символов

| Символ | Описание | Пример |
|--------|----------|--------|
| `\n` | Новая строка | `'строка1\nстрока2'` |
| `\t` | Табуляция | `'колонка1\tколонка2'` |
| `\'` | Одинарная кавычка | `'Это \'тест\''` |
| `\"` | Двойная кавычка | `"Это \"тест\""` |
| `\\` | Обратный слэш | `'путь\\к\\файлу'` |
| `\r` | Возврат каретки | `'текст\rновый'` |
| `\$` | Знак доллара | `'цена: \$100'` |

## Подсказка по форматированию

### Для стихов и текстов:
```dart
String poem = '''
Первая строка
Вторая строка
Третья строка
''';
```

### Для таблиц:
```dart
String table = 'Колонка1\tКолонка2\tКолонка3';
```

### Для списков:
```dart
String list = 'Пункт 1\nПункт 2\nПункт 3';
```

### Для путей Windows:
```dart
String path = r'C:\папка\файл.txt';
```

## Когда что использовать

| Ситуация | Решение |
|----------|---------|
| Многострочный текст | Тройные кавычки `'''текст'''` |
| Таблица или колонки | Табуляция `\t` |
| Список с новых строк | Перенос `\n` |
| Текст с кавычками | Разные кавычки или `\"` |
| Путь Windows | Сырая строка `r'путь'` |
| Регулярные выражения | Сырая строка `r'regex'` |
